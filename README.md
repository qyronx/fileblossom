# File Blossom

A simple file upload and management service built on the Blossom protocol.

## Alternative Site

This repository is an alternative site for https://devareta2.onrender.com/.

If the original site becomes unavailable or inaccessible, this repository can be used as an alternative.

## Features

* File uploading
* Blossom-based file storage
* File management
* Browser-based file access
* Simple and intuitive user interface

## Technology

* HTML
* CSS
* JavaScript
* Blossom Protocol

## About Blossom

Blossom is a protocol designed for storing and managing files as blobs.

File Blossom utilizes the Blossom ecosystem to provide a web-based environment for uploading and managing files.
