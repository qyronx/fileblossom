🔐 작동 원리

File Blossom은 클라이언트 사이드 암호화를 기반으로 하는 파일 공유 도구입니다.

  • 암호화: 파일은 브라우저에서 AES-256-GCM 알고리즘으로 암호화됩니다. 암호화 키는 서버로 전송되지 않으며, URL 프래그먼트(#)에만 저장됩니다.
  • 저장: 암호화된 파일은 Blossom 스토리지 서버에 분할 업로드됩니다. 파일은 SHA-256 해시로 주소 지정되며, 여러 서버에 미러링됩니다.
  • 위장: 파일은 1x1 PNG 이미지 끝에 숨겨져서 PNG 스터빙 기법으로 전송됩니다.
  • 공유: Nostr Gift-wrap을 통해 URL을 단축하여 안전하게 전달할 수 있습니다.

File Blossom 사용방법

  1. 파일을 업로드합니다.
  2. 공유 URL이 나오면 복사해주세요.
  3. 나중에 삭제할 일이 생길 거 같으면 삭제 URL도 복사해두세요.

⚠️ 주의사항

  • 이 서비스는 보안 감사를 받지 않은 상태입니다. 중요한 파일은 본인 책임하에 사용하세요.
  • File Blossom은 프론트엔드 코드를 그대로 베껴가는 것을 허용하지 않습니다.

이용약관은 별도로 제공되지 않으며, 사용자는 본 서비스를 "있는 그대로" 사용하는 데 동의합니다.
